Verdict & gate

The two components that carry spec invariants rather than styling. They exist so no page can invent a state the spec does not have.

Verdict — three states, and there is no fourth

attested refused awaiting human

Each state carries a glyph as well as a colour, so the distinction survives greyscale and colour-blindness. "Awaiting" is styled neutral, never as a soft pass — an unfinished check must not read as a finished one.

<span class="ac-verdict ac-verdict--pass">attested</span>

Gate — the three kinds

deterministic judged human

Kind is always a word, never colour alone. Colour says whether something passed; it does not say what kind of check it was. A gate badge is therefore neutral until a verdict attaches to it.
